## 구성과 업로드

PNG 33개 + GIF 20개, 총 53개. 모두 가로 860px이며 파일별 20MB 미만입니다.

ZIP을 풀고 `01_업로드_이미지` 안의 001~053을 스마트에디터 ONE의 **사진**으로 순서대로 첨부합니다.
기본 세로 배치·원본 비율로 사용하고, 이미지 사이에 빈 줄을 넣지 않습니다.
ZIP 안의 `전체_미리보기.html`을 열면 실제 PNG·GIF를 연결한 전체 화면을 볼 수 있습니다.
